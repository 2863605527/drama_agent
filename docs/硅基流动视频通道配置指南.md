# 通用 HTTP 通道对接硅基流动（SiliconFlow）配置指南

> 适用版本：最新版（前端「模型通道」弹窗 + `http_presets.py` 平台自动识别）
> 本文是「通用 HTTP 通道怎么填」的硅基流动专题；三通道总览见 [`媒体通道配置教程-cv-ark-http.md`](媒体通道配置教程-cv-ark-http.md)。

---

## 〇、先说结论：前端只需要填 3 样东西

在「模型通道」弹窗里选择 **通用 HTTP** 通道，图片 / 视频两个标签页各填：

| 字段 | 图片 | 视频 |
|---|---|---|
| **服务地址（base_url）** | `https://api.siliconflow.cn` | `https://api.siliconflow.cn` |
| **Token** | `sk-` 开头的硅基 API Key | 同一个 Key 即可 |
| **模型名** | `Kwai-Kolors/Kolors`（文生图） | `Wan-AI/Wan2.2-I2V-A14B`（图生视频） |

其余技术字段（图片结果路径、尺寸字段、视频提交/轮询地址、任务 id 路径、状态值、视频 URL 路径、参考图字段等）
**全部由后端按域名自动识别补全**，不需要你手动填。这就是 `tools/http_presets.py` 的职责：识别 `siliconflow.cn` 后自动套用硅基预设。

> 为什么不列死模型下拉框？平台模型迭代快、各家模型名差异大，模型名改为**手动填写**，最新模型随时能用。

## 一、申请 Key（1 分钟）

1. 打开 👉 **https://cloud.siliconflow.cn** → 注册 / 登录；
2. 右上角头像 → **API 密钥** → **创建 API 密钥**；
3. 复制 `sk-` 开头的 Key（只显示一次，丢了就删掉重建）；
4. 充值一点余额（图/视频按量计费，**不出图不扣费**）。

## 二、前端配置与验证

1. 登录系统 → 左下角「模型通道」卡片 → 打开配置弹窗；
2. **大模型**标签页：OpenAI 兼容通道，填 `https://api.deepseek.com` + DeepSeek Key + 模型名（如 `deepseek-chat`）；
3. **图片**标签页：通道选「通用 HTTP」，按上方表格填；
4. **视频**标签页：同上；
5. 点「保存」→ 每段可用「连通测试」验证：
   - **大模型**：真实发一次 ping（会消耗极少额度）；
   - **图片 / 视频**：只校验凭据完整性 + 后端按域名识别预设，**不真正出图/出片，不烧额度**；
6. 保存后配置 **Fernet 加密落库**，接口只回掩码；任务提交时会把当时的配置**快照**进任务，改配置不影响已在跑的任务。

> 踩坑修复记录（历史问题，现已全部修复）：
> - 早期图片/视频两个地址都要填才通过校验 → 现只需 `base_url`，平台自动拼路径；
> - 保存后再次打开弹窗「连通测试」报错 → 掩码回读误判为空值，已修复为「掩码/空值沿用库中旧值」；
> - 点击生成图片没反应 → 已补前端 loading/计时动画 + 后端日志兜底。

## 三、硅基预设自动补全了什么（了解即可）

识别到 `siliconflow.cn` 后，后端自动填（你手动填的高级字段优先覆盖）：

| 环节 | 自动补全值 |
|---|---|
| 图片提交路径 | `/v1/images/generations` |
| 图片尺寸字段 | `image_size`（如 `1280x720`） |
| 参考图字段 | `image`（图生图：白天→黑夜、画风参考） |
| 图片结果路径 | `images[0].url` |
| 视频提交路径 | `/v1/video/submit` |
| 视频轮询 | POST `/v1/video/status`，body `{"requestId": "{task_id}"}` |
| 任务 id 字段 | `requestId` |
| 状态字段 / 成功值 | `status` / `Succeed` |
| 视频 URL 路径 | `results.videos[0].url` |
| 提交时剔除字段 | `duration`（硅基 Wan 视频时长由模型决定，不传自定义时长） |

## 四、常见问题

**Q1：连通测试通过，但生成图片报错？**
看执行日志（前端「工程执行日志」卡片 / `docker compose logs drama-agent`）。常见原因：
- Token 余额不足 → 硅基返回 402/403，去控制台充值；
- 模型名写错 → 换成硅基控制台「模型广场」里展示的**完整模型名**（含厂商前缀，如 `Kwai-Kolors/Kolors`）；
- 该模型不支持图生图 → 参考图（白天图/画风图）会自动转 base64 传入，选支持图生图的模型（如 Kolors、FLUX.1 系）。

**Q2：视频时长多长？**
硅基 Wan 系模型时长基本固定（约 5s），所以后端提交时自动剔除 `duration` 字段；短剧分镜会按「同场景多分镜合并成一个片段」的方式适配，不需要你手动改。

**Q3：想用别的平台（智谱、OpenAI 兼容等）？**
同样只填 `base_url` + Token + 模型名。后端按域名识别内置预设（硅基 / 智谱 / OpenAI…），未识别的域名用 OpenAI 兼容兜底默认；特殊平台可在「高级设置」里手动覆盖提交/轮询路径等字段。

**Q4：模型名太新，预设里没有？**
模型名是手动填写的，不存在预设列表限制；只要该平台该模型真实存在、且协议与预设匹配即可。
