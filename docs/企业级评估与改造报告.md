## 三、架构亮点（评估后确认无需改动）

1. **MCP 子进程隔离**：LLM/图片/视频/TTS 各占一个 stdio 子进程，`_PersistentChannel` 单连接 + owner task 串行 + 断线自动重建重试；ContextVar 按任务绑定通道配置，多任务并发互不串扰。
2. **四重安全 GC**：数据库引用集合为空直接跳过 → 只删已登记 → 现场确认无引用 → 非用户上传；未登记文件一律保留只计数。
3. **SSE 自愈**：历史事件先重放、双水位（seq/ts）去重、8 秒看门狗轮询兜底、视频 URL 合并保护，容器重启不丢进度。
4. **通用 HTTP 平台自动识别**（`http_presets.py`）：用户只填地址/Key/模型名，域名识别后自动补全提交/轮询/结果路径等协议细节，未识别平台走 OpenAI 兼容兜底。
5. **任务快照**：提交时把用户通道配置快照进任务行，跑任务不受事后改配置影响；图片/视频重绘用最新配置。
