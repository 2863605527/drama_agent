# 升级指南：切换到火山方舟 Seedance / Seedream（人物、场景一致性大幅增强）

> 适用版本：最新版 ｜ 预计耗时：15~30 分钟 ｜ 全程在**前端「模型通道」弹窗**操作，不需要改任何代码、不需要改 `.env`、不需要重启服务

---

## 一、先说结论：ark 通道的效果到底如何？

| 对比项 | `volc_cv`（火山即梦 jimeng） | `volc_ark`（方舟 Seedance + Seedream） |
|--------|--------------------------------------|-----------------------------------------------|
| **角色一致性** | 弱——靠"参考图 + prompt 文字描述"双重作用，多次生成可能换脸/换装 | **强**——原生 `role=reference_image` 参考图机制，多次生成同一角色基本一致 |
| **场景一致性** | 弱——prompt 文字描述为主 | **强**——视频以场景图/角色图为参考锚定 |
| **真人写实风格** | 弱——jimeng 通用模型偏插画 | **强**——Seedream 5.0 写实效果好（皮肤毛孔/光影/镜头质感） |
| **原生音频** | 无，靠 edge-tts 后期配音 | **有**——Seedance 原生生成声音+台词（前端开启「原生音频」开关） |
| **视频时长** | 只有 5s/10s 两档（超出会被 clamp） | **1~15 秒任意时长**，原生精确，不裁剪不压缩 |
| **失败率** | 较高（50412 内容审核/参数错误较常见） | 较低 |

**重要说明（诚实版）**：
- Seedance 的参考图一致性是**大幅增强**，不是绝对 100%——生成式 AI 模型每次生成仍有随机性，可能出现轻微的光线/表情/细节差异。
- **想最大程度锁定一致性**，请配合以下操作：
  1. 角色立绘描述写详细（发型/发色/瞳色/服装款式/配饰）
  2. 每次生成都用**同一张**角色立绘/场景图（不要换图）
  3. 场景描述写清"构图、建筑、物件、光线方向"
- 视频生成是"参考图 + prompt"共同作用，**参考图越清晰、prompt 越具体，一致性越高**。

### ⚠️ 重要：cv 通道（即梦）的"白天黑夜不一致"是模型能力限制

火山即梦的 `cv_process` 接口**只支持文生图**——图生图 req_key（`seededit_v2.0_i2i` / `jimeng_image2image_*` 等）全部报 50200 "req_key not supported"。即梦视觉服务**不提供图生图 API**。

意味着 cv 通道下：
- ✅ 角色立绘 → 片段视频：cv 通道的 jimeng_t2v_v30 **支持** `image_url` 参考图（视频可参考立绘）
- ❌ 白天场景图 → 黑夜场景图：**不支持图生图**，只能靠文字描述"构图与白天一致"，模型不一定强遵守

**根本解决方案**：切到火山方舟 Seedream（如 `doubao-seedream-5-0-260128`），它**原生支持 image_to_image 能力**——传 day_image_url 作为参考，黑夜图自动基于白天图做风格迁移，建筑/物件/构图严格一致。

## 二、开通火山方舟（约 10 分钟，一次性）

> 前提：你已有火山引擎账号（即梦 cv 通道用的就是同一个火山账号体系）。

### 第 1 步：登录火山引擎控制台
打开 👉 https://console.volcengine.com/ （用你的火山账号登录，和即梦同一账号）

### 第 2 步：开通「方舟」服务
1. 顶部搜索框搜「**方舟**」（火山方舟 Ark）
2. 点击进入「火山方舟」控制台
3. 首次进入会提示开通，点击「**立即开通**」即可（免费开通，按量付费）

### 第 3 步：在模型广场开通 Seedance + Seedream
1. 左侧菜单找到「**模型广场**」/「模型管理」
2. 搜索并「开通」以下两个模型：
   - **Seedance**（视频生成）：如 `doubao-seedance-2-0-260128`（标准版，以控制台为准）
   - **Seedream**（图片生成）：如 `doubao-seedream-5-0-260128`
3. 开通后记录模型名称（也叫 Model ID，形如 `doubao-seedance-2-0-260128`）

> 💡 如果搜索不到，检查控制台区域是否为「北京」；模型名称以控制台实际显示为准，复制到前端模型名输入框即可。

### 第 4 步：创建 API Key
1. 左侧菜单「**API Key 管理**」→「创建 API Key」
2. 密钥以 `volc-sk-` 开头，**复制保存**（只显示一次！）
3. 注意：方舟 Key（volc-sk-xxx）和即梦的 AK/SK **不通用**，是两个独立凭据

## 三、前端弹窗切换（约 2 分钟，无需重启）

1. 登录系统 → 点击**左下角「模型通道」卡片**，打开配置弹窗；
2. **图片**标签页：通道选「**火山方舟 ARK**」→ 填 API Key（`volc-sk-...`）→ 模型名填 `doubao-seedream-5-0-260128`（以控制台为准）；
3. **视频**标签页：通道选「**火山方舟 ARK**」→ 填同一个 API Key → 模型名填 `doubao-seedance-2-0-260128`；
   - 分辨率选 `720p`、宽高比选 `9:16`（竖屏短剧）；
   - **原生音频开关打开**：Seedance 视频自带台词人声，跳过 edge-tts 配音；
   - 视频时长 1~15 秒由剧本分配，系统自动适配（无需手动配置时长档位）；
4. 点「**保存**」→ 点「**连通测试**」验证（LLM 真实 ping；图片/视频校验凭据完整性，不烧额度）；
5. 新任务 / 重绘 / 重生成立即使用新通道，**无需重启服务**。

## 四、验证是否生效（2 分钟）

1. 打开 `http://127.0.0.1:8010/`（Ctrl+F5 强刷）
2. 新建任务（或继续旧任务），画风选 **realistic（真人写实）**
3. 生成角色立绘 → 应该明显是真人写实（皮肤纹理、电影感、非插画）
4. 生成场景图（白天→黑夜）→ 黑夜基于白天，构图一致
5. 生成片段视频 → 人物外貌与立绘一致、场景与场景图一致，且**视频自带声音**
6. 侧边栏「模型通道」卡片应显示：LLM 你的配置 · 图 火山方舟ARK · 视频 火山方舟ARK

## 六、常见问题

**Q1：ark 通道报错 50400 / Access Denied？**
A：方舟 Key 未开通对应模型，或 Key 过期。回到「模型广场」确认 Seedance/Seedream 已开通，重新创建 Key 并在前端弹窗更新。

**Q2：报错"模型不存在"（model not found）？**
A：模型名和控制台不一致。打开控制台「模型广场」复制实际 Model ID 填回前端弹窗的「模型名」（手动填写，不受下拉限制）。

**Q3：切回即梦 cv 通道？**
A：前端弹窗里把图片/视频通道改回「火山即梦 CV」，填 AK/SK + req_key 即可，随时互切、互不影响。

**Q4：ark 通道更贵吗？**
A：火山按量付费，Seedance 2.0 比 jimeng 略贵，但一致性和质量显著提升。建议先用 5~10 条视频试跑评估。

**Q5：能同时用即梦出图 + Seedance 出视频吗？**
A：可以。图片标签页选「火山即梦 CV」、视频标签页选「火山方舟 ARK」——互不干扰，按需自由组合。
